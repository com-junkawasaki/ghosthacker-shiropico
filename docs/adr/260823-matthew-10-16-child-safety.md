# ADR-260823: マタイ10:16を子供の安全行動へ翻訳する

**Status:** accepted

**Date:** 2026-08-23

## Context

従来のシリーズ設計は7+の痛快アクションと技術教育を中心にし、幼い子供を現実的な危険へ置く場面や、
シロが最後にすべて解決する反復を含んでいた。作者核は、3歳の子供でも安心して触れられ、純真な
子供が狼や欺きに惑わされず、キリストと共に救われる物語を求める。

## Decision

1. マタイ10:16を「見る・離れる・信頼できる相手へ話す」の三動作へ翻訳する。
2. 3歳児安心ゲートを、主対象年齢7+や市場レーティングとは別の内容安全基準として設ける。
3. 子供を現実的な目前の危険へ置かず、敵は恐ろしい宗教像ではなく欺く仕組みとして表す。
4. シロは救済を独占せず、安全確保を引き受けながらピコへ選択を返す。
5. キリスト教的起点は作者核として保持するが、改宗、教派、服従を救済条件にしない。
6. 翻訳・派生脚本は日本語のcanonical scenarioが安全ゲートを通った後に再生成する。

## Consequences

- 幼い子供が同じ画面を見ても、恐怖や自責を持ち帰りにくくなる。
- アクションの勝敗が、怪物を倒すことから危険を一人で抱えない選択へ移る。
- 既存翻訳には旧脚本が残るため、公開前に日本語正本から再同期する必要がある。
- 7+向けの熱量は残せるが、現実的な危害、威圧音、追跡の強度は再演出が必要になる。
