# 『GHOST HACKER ― シロとピコ』 第15話ネーム

## 「みどりの ままで」

**19P／週刊連載 第15話 — Arc 1 最終回**
Arc 1 構成は `jump/arc-01.md` ／ 企画書は `jump/SERIES-PROPOSAL.md`

### ネーム記法
- ページ見出しの `右` / `左` は右綴じでの位置。**`左` ページの最終コマが「めくり」＝ヒキ**
- `◀ めくり`＝引きのコマ、`◆ 見開き`＝2ページぶち抜き
- 数字はコマ番号、`【 】` は構図、`>` はセリフ、`SE:` は効果音、`M:` はモノローグ

### 第15話の設計
| 項目 | 内容 |
|---|---|
| やらかし | **なし**（14話に続き2回目。**やらかさないことが、卒業の証明**） |
| 提示 | **シロが、白いイヤーカフを 指で弾いてよこす**（第1話 P.44-45 とまったく同じ構図・同じ動作） |
| **ピコの答え** | **緑のままでいる**。「**まだ、いっぱい まちがえたい**のだ」 |
| 選択の代償 | **緑のままだと、Wolves は「まだ勧誘できる子」として狙い続ける**。それを知ったうえで選ぶ |
| 回収 | オーリオ「——**そろそろ、犯罪では ありません**」 |
| ラスト | 本物の国際線。行き先は**ドバイ** |
| 引き | 雲の上に**クロ**。「**みどり、か。……いちばん、こちらに 近い色だ**」 |

> **この回でいちばん大事なこと**
> ピコに白を**断らせる**のであって、**取り上げない**。
> ちゃんと差し出され、ちゃんと似合い、ちゃんと**受け取る資格がある**と全員が認めたうえで、
> 本人が返す。そうでないと「まだ弱いから緑」という話に落ちて、選択にならない。
>
> **断る理由は2枚重ねにする。**
> ① まだ間違えたい（＝1〜13話のやらかしが、全部 肯定される）
> ② 白は師匠の色。**師匠の真似をすると、自分がいちばん弱くなる**（＝13話の直接の回収）
> ①だけだと「意識高い子どもの標語」になる。②を足すと、**この15話を読んできた読者だけの理屈**になる。
