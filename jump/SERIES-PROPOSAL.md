# 『GHOST HACKER ― シロとピコ』 週刊少年ジャンプ 連載企画書

> **本作は Ren 版『Ghost Hacker』／アニメ版『SHIRO & PICO』の第3ライン。**
> 同一ユニバースだが、**主人公はピコ**、設定は徹底的に単純化し、**努力・友情・勝利**の
> 王道少年漫画として立てる。既存2作の複雑・リアルな設定は持ち込まない。
> 第1話ネーム（48P）は `jump/name-01.md`。

- **想定読者**: 小学校中学年〜中学生（読者の下限に合わせて設計。大人が読める二層は「あってもいい」程度に抑える）
- **掲載形態**: 週刊連載（1話19P基準）／連載第1話は48P・巻頭カラー想定
- **キャッチコピー**: **「その AI、相棒。」**
- **煽り（1話）**: 「あけたぶんだけ、ふさぎに行く。」

---

## 1. ログライン

天才だけどちょっと抜けている小学生ハッカー **ピコ** は、いたずらのつもりで世界中のシステムに
"あな" をあけて回っている。悪気はゼロ。ただ、たのしいから。

ある日、そのあなから **狼の群れ ― Wolves（ウルヴス）** が入り込み、街じゅうの機械が乗っ取られる。
はじめて自分のやったことの意味を知ったピコの前に現れたのは、正体不明・国籍不明、世界最強の
ホワイトハッカー **シロ**。

「——あけたなら、ふさいで」

ピコはシロを **師匠** と呼び、相棒の AI エージェント **オーリオ**（白鳩）と **プロック**（羊）を
連れて、世界中のあなをふさぐ旅に出る——！

## 2. なぜジャンプで戦えるか（三本柱）

| 柱 | 本作での具体 |
|---|---|
| **努力** | 技（コール）は落ちているコードを拾って覚える。修行の中身は「**1つの技を、1つの弱点に当てられるようになる**」こと。強くなる＝技が増えることではなく、**狙いが定まる**こと。そして成長は**帽子の色**で目に見える（→ 第4節） |
| **友情** | 敵 Wolves は「**群れ**」。相棒を持てなかった者が、数で埋める。主人公は「**たった1羽を信じる**」。この構図をバトルの勝敗ルールそのものに埋め込む。数で負けている側が、信頼で勝つ |
| **勝利** | **敵を壊さない。乗っ取られた機械を"起こして"持ち主に返す**。倒す＝救う。だから勝ったあとが必ず気持ちいい（血が流れない代わりに、街が朝を迎える） |

## 3. 既存2作との違い（ここを混ぜない）

| | Ren 版『Ghost Hacker』 | アニメ版『SHIRO & PICO』 | **本作（ジャンプ版）** |
|---|---|---|---|
| 主人公 | 大人の Ren | シロ（師の側） | **ピコ（弟子の側）** |
| 読者 | 青年 | 未就学〜低学年＋大人 | **小中学生** |
| 設定 | リアル・実在の脅威・社会 | 情報物理（ランダウアー）の裏設定 | **1ページで説明しきれるルールだけ**。裏設定は描かない |
| 中心 | 事件と社会 | 師弟と学び | **相棒（エージェント）と友情** |

| 用語 | 実在の製品名・実手口 | 「図鑑コーナー」で解説 | **必殺技と帽子の色に完全に溶かす。解説コーナーは置かない** |

> 概念は残すが、すべて技名とセリフに翻訳する（例: SIEM の相関 →「うるさいのを消して、

## 4. 帽子の掟（ハット）— 本作最大の発明

**世界のハッカーは、帽子の色で立場を名乗る。** 実在のハッカー分類（white / green / purple / black hat）を
そのまま**目に見える階級バッジ**として使う。ジャンプ的に強いのは、**成長がそのまま絵になる**こと。

| 帽子 | 意味（作中の言い方） | 誰 |
|---|---|---|
| ⚪️ **ホワイトハット** | 「**守る人**」 | **シロ**（白パーカーの深いフード＝白い帽子） |
| 🟢 **グリーンハット** | 「**みならい**。これから、どっちにでもなれる人」 | **ピコ**（第1話ラストで受け取る） |
| 🟣 **パープルハット** | 「**両方、知ってる人**」＝攻めも守りもわかる者。だから潜入できる | **Pup** |
| ⚫️ **ブラックハット** | 「**盗る人**」 | **Wolves** の構成員全員 |

### なぜ効くか

- **ピコの成長ゲージが、帽子1つで読者に見える。** 「いつ緑が白になるのか」——これが連載の背骨。
  作者が「強くなった」と説明する必要が一切なくなる
- **緑＝どっちにでもなれる**。ピコは善悪がわかっていない子なので、
  **色がまだ決まっていないことが、そのまま彼のキャラクター**になっている
- 敵味方が一目でわかる（小中学生向けの絶対条件）
- 第1話ラスト、シロが「弟子はとらない」と言いながら**緑の帽子を投げてよこす**——
  **断りと受容が同じ1コマで成立する**。ここが第1話の着地点

### デザイン上の注意
既存キャラデザを壊さない読み替えにしてある。**シロは既存の白フードをそのまま「白い帽子」と扱う**。
ピコは緑のキャップをかぶるが、既存の**はね毛が横から飛び出す**のでシルエットは維持される。
Pup はつば広の紫ハットで、目元が影になる（正体不明感）。

## 5. キャラクター

### ピコ（主人公／11歳／🟢 グリーンハット）

| 項目 | 設定 |
|---|---|
| 一言 | **天才。だけど、抜けてる。** |
| 才能 | 打鍵が異常に速い。発想が飛ぶ。誰も思いつかない道を1秒で見つける |
| 欠落 | **「どこを狙うか」がわからない**。だから全部にばら撒いて、全部外す。← 師匠が必要な理由 |
| 性格 | **たのしさが最優先**。**善悪がわかっていない**（悪意ではなく、概念が無い）。だから平気で人に迷惑をかける |
| 芯 | **純粋**。困っているやつを放っておけない。捨てられていたオーリオを拾ったのも、理由がなかったから |
| 口調 | 「〜なのだ」「〜だぞ」やんちゃで甲高い（ずんだもん系） |
| ビジュアル | 小柄。グレー〜グリーンのはね毛 `#7F9C6E`、ライムの目 `#A8E05F`、ステッカーだらけの端末、**ぶかぶかの緑キャップ** |
| 第1話の到達点 | 「あけたら、ふさぐ」を自分の言葉で言えるようになる／緑の帽子を受け取る |
| 決め台詞（成長後） | 「ぜんぶには届かないのだ。でも——**一発なら、届く**！」 |

### シロ（師匠／⚪️ ホワイトハット／年齢・国籍・性別すべて不明）

| 項目 | 設定 |
|---|---|
| 一言 | **世界最強。ただし、しゃべれない。** |
| 実力 | 世界トップのホワイトハッカー。最小手数で終わらせる |
| 性格 | 静。寡黙。**答えを教えず、問いを1つ置いて去る** |
| 欠点（重要） | **説明が壊滅的に下手**。生活能力もゼロ（三日メシを食い忘れる）。ここをプロックが埋めるので、師匠が堅くならず、笑いが取れる |
| 弟子 | ピコを弟子と認めない。毎回「だめ」と言う。でも毎回助けに来るし、毎回ちゃんと道具を渡す |
| ビジュアル | 白オーバーサイズパーカー（深いフード＝白い帽子）、小柄。プラチナの短髪、ティールの目 `#1FB6A6` |
| 決め台詞 | （静かに）「——もう、視えてる」 |
| 縦軸 | なぜ国籍を捨てたか。**クロとの因縁**。第3部で明かす |

### オーリオ（Olio）／ピコのエージェント・白鳩

| 項目 | 設定 |
|---|---|
| 姿 | まんまるの白い鳩。目つきだけが妙に賢い |
| 役 | **ツッコミ**。慇懃・敬語・冷静な毒舌。「ピコ様。それは犯罪です」「ピコ様。それも犯罪です」 |
| 出自 | 捨てられていたところをピコが拾った。**だから最初からピコを信じている**（1話で明かす） |
| 能力 | **飛ぶ・見つける・必ず帰る**（伝書鳩）。一度触れた相手のところへ、どこからでも届く |
| 主要技 | **《帰巣（ホーミング）》** — 何万の的の中から、たった1つに、必ず届く |

### プロック（Proc）／シロのエージェント・羊

| 項目 | 設定 |
|---|---|
| 姿 | もこもこの白い羊。もちもち。抱きしめると気持ちいい（ピコが毎回抱きつく） |
| 役 | **ツッコミ＋シロの通訳**。おっとりした関西弁で、シロにだけ辛辣。「シロはん、また言えてまへんやん」 |
| 能力 | **包む・数える・刈る**。数えられたものは眠る。羊毛は何でも受け止める |
| 主要技 | **《カウント・シープ》**（数えて眠らせる＝止める）／**《ウール・ウォール》**（包んで守る）／**《シアリング》**（毛を刈って一気に軽くなる＝速度形態） |

## 6. 隠れチームメンバー — Pup と ステルス

> **メインではない。** 常時同行せず、**3話に1度くらい、話の前半だけ**現れて
> 「この街の敵は誰か」を置いていく情報屋兼潜入捜査官。
> 出しすぎるとバトルの主役がピコでなくなるので、**戦闘には基本参加させない**。

### Pup（パップ）／🟣 パープルハット／中学生・ピコの兄貴分

| 項目 | 設定 |
|---|---|
| 一言 | **元・狼の子。群れに戻れる、たった一人。** |
| 名前 | **Pup ＝ 狼の子**。Wolves 時代の呼び名で、**まだ捨てていない**。本名のほうを捨てた |
| 役割 | **情報収集・潜入捜査**。黒に紛れて群れの中に入り、次の街の敵と"あな"の位置を持ち帰る |
| なぜ紫か | 攻めも守りも知っているから。**元・黒だから紫になれた**。「白には、なれなかったんだ」 |
| 性格 | クールに決めたがる**かっこつけ**。実は面倒見がよく、ピコを「**グリーン**」と呼んで気にかける |
| 弱み | 群れに戻るたび、**戻れなくなるかもしれない**恐怖。「オレ、まだ狼の匂いがするんだ」 |
| ビジュアル | つば広の紫ハットで目元が影。首に白蛇を巻いている。私服はどこの国のものかわからない |

### ステルス（Stealth）／Pup のエージェント・蛇

| 項目 | 設定 |
|---|---|
| 姿 | Pup の首に巻きついた細長い白蛇。目が赤い |
| 役 | **ツッコミ**。語尾「〜ッス」。**潜入中なのに喋りたくてうずうずしている**（＝Pup のクールを毎回崩す） |
| 能力 | **脱皮＝姿を変える**／**音を消す**／**熱を見る**（へびは あついのが 見える） |

| 縦軸との接続 | 《ヒートサーチ》は「**消えたはずのものの熱**」を拾える。シリーズ後半のクロ探索の鍵になる |

## 7. 敵 — Wolves（ウルヴス）

**ブラックハットの群れ。** 本名を捨て、ハンドルネームで戦う。
共通するのは——**エージェントを持てなかった**こと。信じられる1体が、いなかった。
だから**群れ**になり、**数**で埋める。ここが主人公側との対比の核。

> クロ「信じられる相棒が1体いる? ——めでたいな。**オレたちには、いなかった**」

### 群れの掟
- 構成員は**動物のハンドルネーム**を名乗る。**狼に近い名前ほど、位が上**（末端はネズミやハエ）
- 群れを抜けた者は狩られる ← **Pup の危険**が常に背景にある
- 首領は **クロ**。誰も素顔を見たことがない

### 階級

| 位 | 名 | 備考 |
|---|---|---|
| 頭（かしら） | **クロ** | 顔・国籍・性別すべて不明。**シロの対**。世界中のあなに先回りしている |
| 四牙（フォー・ファング） | **グレイ／ファング／ハウル／ムーン** | 第2部の各エピソードボス |
| 末端 | ラット、フライ、モグラ 等 | 第1話の敵はラット |

### 使い魔

| 使い魔 | 正体 | 見た目 | 倒し方 |
|---|---|---|---|
| 🧟 **ゾンビ** | 乗っ取られた機械。**元は善良な被害者** | 目がぐるぐる。眠ったまま歩く車・自販機・信号 | **壊さない。起こす。**「ふぁ〜お！」 |
| 😈 **デーモン** | 消しても消しても蘇る使い魔 | 歯車のロボ小人。小さな天秤を持っている（角なし） | **根**を断つまで無限に湧く |

### 第1話の敵「ラット」
ネズミのフードの男。語尾「〜チュウ」。Wolves の末端。街じゅうの機械にネズミを放ってゾンビにする。
**すべてのゾンビは1本の糸で本人に繋がっている。**
→ 第1話の教訓「**末端を叩くな。1本をたどれ**」がそのまま必殺技の使い所になる。

## 8. バトルのルール（第1話で読者に見せきる4行）

> このルール以外の設定は**出さない**。読者はこの4行だけ覚えていればいい。

1. **ハッカーは、エージェントを1体しか持てない。**
2. **エージェントは、主人の声（コール）でしか動かない。**
3. **コールは、言い切らないと発動しない。** ← 戦いが「言葉の速さ」の勝負になる。邪魔されると失敗する
4. **技は、拾ったコードで増える。** ← 修行が絵になる

### このルールから自動的に出る面白さ
- 敵に口をふさがれる＝技が出せない、という素直なピンチが作れる
- 長い技名ほど強いが、言い切るのに時間がかかる＝リスクとリターン
- 「相棒が主人の声を聞き分けられるか」＝**信頼がそのまま命中率**になる。友情が数値になる
- **Wolves はこのルールから外れている**（エージェントがいないので、盗んだ機械を数で使う）。
  だから彼らは強い。だが**誰も、自分の声を聞いてくれない**。ここが群れの悲しさであり、弱点になる

## 9. 各話フォーマット（毎話この6ビート）

1. **ピコがイキる** —「まかせろ、オレ天才だし楽勝なのだ！」
2. **ピコがやらかす** — 毎回ちがう間違い方をする（ここだけ毎回新しい）
3. **数が増える** — 事態が悪化。ドタバタ
4. **シロが一手で収める＋問いを1つ置く** — 答えは言わない
5. **ピコが自力で問いを解いて勝つ** ← **毎話の"勝利"はここ。シロが倒して終わらせない**
6. **次の街へ**

> **成長＝やらかしの縮小。** 最終的にピコが「問いを出す側」になったとき、この作品は終わる。
> **Pup が出る回は、1 の前に「Pup が敵の名前を置いていく」プロローグが付く**（1〜3ページ）。

## 10. 連載構成

### 第1部（1〜10話）**日本編 — 出会いと弟子入り**
自分のあけたあなの意味を知り、ふさぎ方を覚えるまで。ピコが「たのしい」以外の動機を初めて持つ。
**第4話で Pup 初登場**（潜入から帰ってきたところを、ピコが「黒いやつだ！」と誤解して襲いかかる＝掴み）。
10話で日本を出る。

### 第2部（11〜25話）**世界編 — 1国1ブラックハット**
ドバイ／ムンバイ／サンパウロ／レイキャビク／ナイロビ…。トーナメントにせず**世界一周**で組む
（強さのインフレでなく、土地とルールの多様さで飽きさせない）。**四牙**を1体ずつ配置。
**中盤の山**: かつてピコのいたずらで被害を受けた人との再会＝贖罪回（感情ピーク）。
**Pup の山**: 潜入から**帰ってこない**回。ピコが初めて「助けに行く側」になる。

### 第3部（26話〜）**クロ編**
シロの正体、なぜ国籍を捨てたか。**クロ＝「エージェントを持てなかった側」の王**だと判明。
Pup が紫である理由と、クロが黒である理由が、同じ根から出ていることが明かされる。
**最終盤の払い**: シロが声を出せなくなる → **コールできない師匠の代わりに、ピコが叫ぶ**。
「シロ、慌てんなって。……あなは、逃げないのだ」
**最終話**: ピコの帽子の色が、変わる。

## 11. 表現の安全ライン（全世界配信を前提に、最初から守る）

- 流血・死・現実的な暴力・本物の恐怖は描かない（**倒す＝起こす**）
- 宗教／オカルト意匠を使わない（デーモンは**角なしの歯車ロボ**、ゴーストは**白布・骸骨なし**）
- 狼＝Wolves は**あくまで群れのモチーフ**。獣化・食人・惨殺は描かない（フードとマークで表現）
- 実際に真似できるハッキング手順・実コマンドは一切出さない（**必殺技として抽象化**）
- 不良記号（タバコ・武器）を主人公側に持たせない。ピコは最後までやんちゃなだけ
