# 『GHOST HACKER ― シロとピコ』 第9話ネーム

## 「かくしたら、おおきくなる」

**19P／週刊連載 第9話 — Arc 1 感情ピーク②**
Arc 1 構成は `jump/arc-01.md` ／ 企画書は `jump/SERIES-PROPOSAL.md`

### ネーム記法
- ページ見出しの `右` / `左` は右綴じでの位置。**`左` ページの最終コマが「めくり」＝ヒキ**
- `◀ めくり`＝引きのコマ、`◆ 見開き`＝2ページぶち抜き
- 数字はコマ番号、`【 】` は構図、`>` はセリフ、`SE:` は効果音、`M:` はモノローグ

### 第9話の設計
| 項目 | 内容 |
|---|---|
| イキり | 「へーきへーき。ちょっと しくじっただけなのだ」← **空元気**。今回のイキりは嘘 |
| **やらかし** | **こっそり直して、黙っている**。狙われていると知り、一人で片づけようとする |
| 悪化 | **隠したぶんだけ、被害が広がる**。誰も居場所を知らないので、誰も助けに行けない |
| シロの問い | 「**ひとりで背負うのは、つよさじゃない**」 |
| ピコの答え | 全部 話す。かっこ悪くても、順番がめちゃくちゃでも |
| 敵 | Wolves（顔を出さない。**罠だけが出てくる**） |
| 縦軸 | シロ「……**ぼくは、言えなかった**」／Pup「**オレが、群れに戻る**」 |

> **この回の構造上の刃**
> ピコは **オーリオを遠ざけてから、夜に出ている**。エージェントがいなければ**技が撃てない**。
> つまり「隠す」ことが、そのまま「**丸腰で出歩く**」ことになっている。
> オーリオの怒りは感情論ではなく、**構造的に正しい**。ここを外さない。
>
> **もうひとつの刃**: シロは「ひとりで背負うな」と言いながら、**自分がそれをできていない**。
> プロックだけがそれに気づいていて、なにも言わない。**Arc 3「クロ編」の種**はここに蒔く。
