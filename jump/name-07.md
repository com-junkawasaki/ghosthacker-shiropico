**19P／週刊連載 第7話**

### ネーム記法
- ページ見出しの `右` / `左` は右綴じでの位置。**`左` ページの最終コマが「めくり」＝ヒキ**
- `◀ めくり`＝引きのコマ、`◆ 見開き`＝2ページぶち抜き
- 数字はコマ番号、`【 】` は構図、`>` はセリフ、`SE:` は効果音、`M:` はモノローグ

### 第7話の設計
| 項目 | 内容 |
|---|---|
| イキり | 「**師匠から 連絡きたのだ！ 呼ばれてるのだ！**」（＝嬉しさで舞い上がる） |
| **やらかし** | **急いで、確認しない**。送り主の名前が**1文字ちがう**のに、気づかない |
| 悪化 | 街の反対側へ誘い出され、**留守を突かれる**。ピコが**いない**せいで、人が困る |
| シロの問い | 「**急いでるときほど、ゆっくり 読んで**」 |
| ピコの答え | オーリオが「**ずっと 一緒にいた 記憶**」で本物を見分ける（5話の応用） |
| 敵 | **モグラ**（第2話から再登場・成長している） |
| 縦軸 | 偽の呼び出しの**文面が、1年前のピコ自身のいたずらの文面**そのまま |
| 引き | ピコ「……**オレの、むかしの?**」 → **第8話へ直結** |

> **ニセモノの見せ方（1コマで、子どもにわかる）**
> 送り主の名前は「**シ口**」。——カタカナの「ロ」ではなく、**漢字の「口」**。
> 並べて大アップで見せれば、説明なしで全読者が理解できる。
> **ピコは最後まで自力で気づかない。** 気づくのはオーリオ。
> しかも**オーリオは P.3 で言おうとして、ピコに遮られている**。
> 「急いでいて、聞かなかった」がやらかしの本体であって、「見抜けなかった」ではない。
>
> **この回は、ピコが 間に合わない。** 駆け戻っても、もう終わっている。
> Arc 1 で**唯一、被害を止められない回**にして、8話（忘れていた被害者）へ地続きにする。
