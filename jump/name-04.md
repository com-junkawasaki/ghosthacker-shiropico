# 『GHOST HACKER ― シロとピコ』 第4話ネーム

## 「むらさきの、あいつ」

**19P／週刊連載 第4話 — Pup ＆ ステルス 初登場回**
Arc 1 構成は `jump/arc-01.md` ／ 企画書は `jump/SERIES-PROPOSAL.md`

### ネーム記法
- ページ見出しの `右` / `左` は右綴じでの位置。**`左` ページの最終コマが「めくり」＝ヒキ**
- `◀ めくり`＝引きのコマ、`◆ 見開き`＝2ページぶち抜き
- 数字はコマ番号、`【 】` は構図、`>` はセリフ、`SE:` は効果音、`M:` はモノローグ

### 第4話の設計
| 項目 | 内容 |
|---|---|
| イキり | 「黒いやつ 見つけたのだ！ オレが とっちめるのだ！」 |
| **やらかし** | **相手を悪者と決めつける** — 黒っぽい＝敵、と決めて襲いかかる |
| 悪化 | 相手は味方。しかも騒いだせいで**2ヶ月の潜入が飛ぶ** |
| シロの問い | 「**色は、見た目じゃない**」 |
| ピコの答え | **自分が囮になる**。「オレが うるさいのは、とくいなのだ」 |
| 新キャラ | **Pup**（🟣パープルハット）＋ **ステルス**（白蛇） |
| 縦軸 | 「この街に、**四牙**が1体 来てる」 |

> **設計上の要点**
> ① **Pup は一度も反撃しない。** かわすだけ。格上であることと、味方であることを、
>    戦わせずに同時に見せる。
> ② **正体は コートの裏地で 開示する。** ピコが掴みかかったはずみで**コートが 翻り、
>    びっしりと 紫の裏地**が ばさりと 見える。Pup の「両方 知ってる色」が、
>    設定表の話ではなく**絵**になる瞬間。
> ③ **ピコの"うるさい"が、初めて武器になる。** これは13話「うるさく、速く、たのしく」の伏線。
> ④ **第1話ラストの cameo とセリフを対にする。**
>    1話「褒めてるんスか、それ」「ううん。——**心配してる**」
>    → 本話「褒めてるんスか」「ううん。——**たすかった**」
