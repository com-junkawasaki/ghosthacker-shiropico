# 『GHOST HACKER ― シロとピコ』 第12話ネーム

## 「もこもこが、いない」

**19P／週刊連載 第12話 — シロが問いを置けない回**
Arc 1 構成は `jump/arc-01.md` ／ 企画書は `jump/SERIES-PROPOSAL.md`

### ネーム記法
- ページ見出しの `右` / `左` は右綴じでの位置。**`左` ページの最終コマが「めくり」＝ヒキ**
- `◀ めくり`＝引きのコマ、`◆ 見開き`＝2ページぶち抜き
- 数字はコマ番号、`【 】` は構図、`>` はセリフ、`SE:` は効果音、`M:` はモノローグ

### 第12話の設計
| 項目 | 内容 |
|---|---|
| **やらかし** | **早すぎる**。焦って、コールを**言い切る前に**撃つ → 不発（ルール③） |
| 悪化 | プロックを奪われ、**シロが 技を 使えなくなる**。世界最強が、ただの人になる |
| シロの問い | **なし** ← **この回だけ、シロは問いを置けない**。11話まで守ってきた型を、ここで壊す |
| ピコの答え | **ピコが、問いを 出す側になる**「あいつ、なんで 声を ぬすむのだ?」 |
| 縦軸 | ハウルの過去「オレには、**呼んでくれるやつが いなかった**」 |
| 引き | ピコ「じゃあ、——**オレが 呼んでやる**のだ」 |

> **奪われ方のルール（ごまかさない）**
> ハウルは**シロの声を完全にコピーしている**。だから、シロが呼んでも、ハウルが呼んでも、
> プロックには**まったく同じに 聞こえる**。プロックは裏切るのではなく、**どちらにも 従えなくなって
> 動けなくなる**。その隙にハウルが連れていく。
> 結果、シロは**コールしても 誰も 動かない**＝技が撃てない。ルール②から素直に出る帰結にする。
>
> **この回の芯**
> 型（4. シロが問いを置く → 5. ピコが解く）を1度だけ壊す。シロが黙り込んだページで、
> **読者が「あれ、いつもの問いが来ない」と気づく**。その空白を、**ピコが自分で埋める**。
> ここで初めて、師弟の矢印が逆を向く。**最終話（Arc 3）の逆転は、この1ページから始まる。**
