# 『GHOST HACKER ― シロとピコ』 第11話ネーム

## 「こえを ぬすむ やつ」

**19P／週刊連載 第11話**
Arc 1 構成は `jump/arc-01.md` ／ 企画書は `jump/SERIES-PROPOSAL.md`

### ネーム記法
- ページ見出しの `右` / `左` は右綴じでの位置。**`左` ページの最終コマが「めくり」＝ヒキ**
- `◀ めくり`＝引きのコマ、`◆ 見開き`＝2ページぶち抜き
- 数字はコマ番号、`【 】` は構図、`>` はセリフ、`SE:` は効果音、`M:` はモノローグ

### 第11話の設計
| 項目 | 内容 |
|---|---|
| イキり | 「四牙? そんなの、オレの帰巣で 一発なのだ！」 |
| **やらかし** | **勝てる相手だけ選ぶ**。ゾンビを片っ端から起こして「勝ってる」つもりになる |
| 悪化 | **起こした人が「ふぁ〜お」と 声を出す。その声を、ハウルが 覚える**。勝つほど敵が増える |
| シロの問い | 「**きみが勝つほど、あいつが 増えてる**」 |
| ピコの答え | 起こすのをやめる。**先に、本体を探す** |
| 敵 | **ハウル**（四牙・正式登場） |
| 引き | ハウルが**シロの声**で「プロック」と呼ぶ。——**プロックが、振り向く** |

> **この回の仕掛け（読者にだけ先に見せる）**
> P.3 から、**起こされた人の「ふぁ〜お」という声が、細い糸になって空へ 昇っていく**のを、
> **読者にだけ**描く。ピコには見えていない。
> 「善いことをするたび、敵が強くなる」という残酷な構造を、**説明ではなく 絵で** 先に見せ、
> ピコが気づくまでの5〜6ページ、読者に「やめろ」と思わせ続ける。
>
> **この回でピコは、初めて "助けない" を選ばされる。** P.13 で、起こしてほしそうな人の前で
> 手が止まる。ここが今回のいちばん痛いコマ。
