# 『GHOST HACKER ― シロとピコ』 第6話ネーム

## 「ひろったものを、たべさせるな」

**19P／週刊連載 第6話**
Arc 1 構成は `jump/arc-01.md` ／ 企画書は `jump/SERIES-PROPOSAL.md`

### ネーム記法
- ページ見出しの `右` / `左` は右綴じでの位置。**`左` ページの最終コマが「めくり」＝ヒキ**
- `◀ めくり`＝引きのコマ、`◆ 見開き`＝2ページぶち抜き
- 数字はコマ番号、`【 】` は構図、`>` はセリフ、`SE:` は効果音、`M:` はモノローグ

### 第6話の設計
| 項目 | 内容 |
|---|---|
| イキり | 「すごい技 ひろったのだ！ しかも **タダ**なのだ！」 |
| **やらかし** | **拾ったものを、そのまま 食べさせる** |
| 悪化 | **《ふたりの あいことば》が、効かなくなる**。5話で手に入れたものが、真っ先に壊れる |
| シロの問い | 「**ただより、こわいものはない**」（プロックが訳す） |
| ピコの答え | 1行ずつ、自分で読む。**読めなかった部分は、使わない** |
| 獲得 | **なし**。むしろ **技を1つ 捨てる** ← 増やすだけが成長じゃない、を1話まるごと使って言う |
| 縦軸 | Pup「この罠の置き方……**ハウルの狩り**だ」／筐体すべてに**狼のマーク** |

> **なぜ「オーリオがゾンビになる」にしないか**
> 5話で「相棒が敵になる」をやったばかりなので、同じ絵を繰り返すと安くなる。
> ここで壊すのは**5話で二人が作ったもの**——**《ふたりの あいことば》そのもの**にする。
> ピコが必死で手に入れた雨の日の合図を、**拾いもの1つで 自分から 壊す**。
> 前話の勝利を、次話で自分の手で台無しにする ——これが「成長は一直線ではない」の実装。
>
> **捨てる技を、ちゃんと 惜しくする。** P.15-16 で、その技が**本当にかっこよくて 強い**ことを
> 見せてから捨てさせる。惜しくなければ、決断にならない。
