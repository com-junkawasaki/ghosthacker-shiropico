# 『GHOST HACKER ― シロとピコ』 第5話ネーム

## 「おなじ あいことば」

**19P／週刊連載 第5話**
Arc 1 構成は `jump/arc-01.md` ／ 企画書は `jump/SERIES-PROPOSAL.md`

### ネーム記法
- ページ見出しの `右` / `左` は右綴じでの位置。**`左` ページの最終コマが「めくり」＝ヒキ**
- `◀ めくり`＝引きのコマ、`◆ 見開き`＝2ページぶち抜き
- 数字はコマ番号、`【 】` は構図、`>` はセリフ、`SE:` は効果音、`M:` はモノローグ

### 第5話の設計
| 項目 | 内容 |
|---|---|
| イキり | 「オレのコール、かっこいいのだ！」 |
| **やらかし** | **おなじ合言葉を使い回す** — 全部の技のコールが同じ（言いやすいから） |
| 悪化 | 録音され、真似される → **オーリオが、敵の声で動く。相棒に撃たれる** |
| シロの問い | 「**その声、ほんとうに きみの?**」 |
| ピコの答え | 声で呼ぶのをやめる。**オーリオしか知らないこと**で呼ぶ |
| 敵 | **フライ**（撃破） |
| 獲得 | **《ふたりの あいことば》** |
| 縦軸 | フライの捨て台詞「兄貴の声は、**そんなもんじゃない**チュウ」→ 夜空に遠吠え |

> **この回が Arc 1 の心臓。** バトルのルール②（エージェントは主人の声でしか動かない）を
> **恐怖の側から**見せる回であり、同時に「**友情がそのまま鍵になる**」ことを実装する回。
> 13話《ただいま》と14話のハウル戦の勝ち筋は、全部ここから伸びている。
>
> **仕込みの原則**: 解決に使う「雨の日」の記憶は、**第1話 P.4 の回想で既に絵として出している**
> （雨・ダンボール・差し出される手）。本話で足す新情報は「**ピコも傘を持っていなかった**」の
> 一点だけ。既出の絵と矛盾させず、意味だけを反転させる。
