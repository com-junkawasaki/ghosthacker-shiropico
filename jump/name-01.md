**46P（巻頭カラー想定）／連載第1話**
企画書は `jump/SERIES-PROPOSAL.md`

### 読み方（ネーム記法）
- ページ見出しの `右` / `左` は右綴じ単行本での位置。**`左` ページの最終コマが「めくり」＝ヒキ**
- `◀ めくり` はページをめくらせる引きのコマ
- `◆ 見開き` は2ページぶち抜き
- 数字はコマ番号、`【 】` は構図・カメラ、`>` はセリフ、`SE:` は効果音、`M:` はモノローグ

### 第1話の設計
| 項目 | 内容 |
|---|---|
| ピコのやらかし | **あなを、あけっぱなしにする**（通っただけ、なにも壊してない、と本気で思っている） |
| 事態の悪化 | 起こしたそばから隣が眠る＝**叩くほど増える** |
| シロが置く問い | 「**ぜんぶ、やるからだよ**」（答えは言わない） |
| ピコが自力で出す答え | 「**ぜんぶには届かない。1個に、届かせる**」 |
| 決め技 | **《帰巣（ホーミング）》** |
| 引き | **クロ**の名前／**デーモン**の初出 |

## ネーム自評（担当編集向けメモ）

| 観点 | 本ネームでの担保 |
|---|---|
| **つかみ（P1-6）** | 6ページで「主人公が何をする奴か」「なぜ危ないか」が全部わかる。説明台詞ゼロ、全部行動で見せている |
| **ルールの提示** | バトルの4ルールのうち①②③は P.9〜P.23 で自然に見せ、④（技は拾って増える）は第2話に回した。**第1話で説明しすぎない** |
| **努力** | P.25-28 の「目を閉じる」修行。所要は作中30秒だが、ピコの弱点（集中できない）を先に立てているので短くても嘘にならない |
| **友情** | P.19-20（オーリオの過去）と P.27（暗闇で声だけを頼る）と P.31（信じて撃ち出す）の3段で積んだ。**信頼＝命中率**というルールが決め技の説得力になっている |
| **勝利** | シロが倒さない。シロは「問い」を置くだけで、**答えを出して撃つのはピコ**。第1話からこの分担を守る |
| **敵の魅力** | ラットは弱いが「ありがとチュウ、恩人チュウ」の1発で主人公に致命傷を与える。**物理でなく罪悪感で殴る敵**として機能している |
| **引き** | クロの名前とデーモンの初出を最後の4ページに固めた。読者が覚えて帰る固有名詞は **ピコ／シロ／オーリオ／プロック／クロ** の5つだけに絞っている |
| **年齢レーティング** | 流血・死・破壊ゼロ。ラットも眠らされるだけ。宗教／オカルト意匠なし。デーモンは角なしの歯車ロボ |

### 次話に持ち越した宿題
- ピコがコードを拾って技を覚える描写（ルール④）
- シロがなぜ説明できないのか（過去の伏線として、まだ触れない）
- ラットを眠らせたのは誰の指示か（クロ編への線）
