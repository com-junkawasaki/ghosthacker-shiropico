## 0. 方針転換の記録（2026-08-03）

当初、階級を**実際にかぶる帽子**で表現する設計だったが、**全員が帽子をかぶっている絵はダサい**という
判断で撤回した。

- **呼称（ホワイト／グリーン／パープル／ブラックハット）は残す。** 実在のハッカー用語であり、
  この作品の階級語そのもの。セリフの中では今までどおり使う
- **視覚表現はアクセントカラーに落とす。** かぶらない
- **シロとピコは、既存の立ち絵をそのまま使う**（→ §0.5 で参照先を訂正済み）。
  **追加はイヤーカフ1点のみ**
- 新キャラ（Pup／ステルス／ハウル／クロ）は、**シルエットで個性を立てる**

作中で1回だけ、この矛盾を回収する:

> ピコ「その4つ、**ぼうし**って 呼ぶんだろ? なんでなのだ。**だれも かぶってない**のだ」
> プロック「**むかしの 呼び方ですわ**。……かぶってた人らが、おったんです。むかし」

（実装位置: **第1話 P.46 コマ4**。用語の初出と同じコマで回収するので、
読者は最初から「かぶらないもの」として覚える）

## 0.5 参照先の訂正（2026-08-03、オーナー判断）

**当初この文書は参照先を `kamishibai-*-gen2.png` と書いていた。誤りだった。**
`character-refs/` には互いに矛盾する2系統が同居していて、キャラデザ仕様書の色は
最初から `emotions/` 系を指していた。

| | 正（canon） | 除去 |
|---|---|---|
| **シロ** | `emotions/shiro/*.png`（12表情）。**女の子**。白い衣装＋**白いキャップ**、銀白の髪にシアンのメッシュ、大きなシアンの目 | `kamishibai-shiro-gen2*.png`。ティールのパーカー＋**フードに獣耳**＋黒目 |
| **ピコ** | `kamishibai-pico.png`（**旧世代・基準**）＋ `emotions/pico/*.png`（12表情）。グレー〜チャコールの髪に淡い黄緑のハイライト、**ライムのパーカー**、大きな白目に小さい黒い瞳、**ノートPCを抱えている** | `kamishibai-pico-gen2*.png`。オレンジ髪＋オレンジのパーカー＋茶色の目 |

**除去する側は本作のシロ／ピコではない。** `ASSETS-DATALAD.md` によれば「ゆっくり」
チャンネルの既存キャストからの流用素材で、仕様書のどの記述とも一致しない。

⚠ **実ファイルの削除はまだできていない。** `ghosthacker-shiropico-assets` は 2026-07-29 に
GitHub 上で archive され read-only。削除は owner の unarchive 後で、それまでは
**本節と `character-design-spec.json` の `refPolicy` が「使ってはいけない」の正本**。

### この訂正で変わったこと

- **シロは女の子**（オーナー確認）。**一人称は「私」、口調は四国めたん風**
  （「〜だわ」「〜かしら」、少し高飛車、でも世話は焼く）。
  アニメ版 spec が最初から `voicevox:2 (四国めたん)` を指定しており、その復元。
  **寡黙さは維持する** — 口調だけがめたんで、喋る量は増やさない
- **シロはフードではなくキャップ**をかぶっている。旧記述「丸く垂れるフード」は誤り。
  結果として **Wolves のフードと混同する危険は最初から無かった**（§3 を更新）
- **ピコのライムは「目」ではなく「パーカー」**。旧仕様の lime eyes は誤り
- **ピコはノートPCを常に抱えている**。これが最大の識別記号（§3 を更新）
- 偶然だが、**シロの白いキャップとピコのライムのパーカーが、そのまま階級色になっている**。
  帽子バッジを廃止した判断（§0）と矛盾しない——**衣装が最初から色を持っていた**というだけ

## 1. アクセントカラー ＝ 階級

| 呼称 | 色 | 誰 | どこに出るか |
|---|---|---|---|
| ⚪️ **ホワイトハット** | 白 ＋ ティール `#1FB6A6` | **シロ** | 白い衣装と白いキャップ（既存デザインそのもの）／シアンの目とメッシュ／プロックの光 |
| 🟢 **グリーンハット** | ライム `#A8E05F` | **ピコ** | **ライムのパーカー（既存）**／髪の淡い黄緑のハイライト（既存）／左耳のイヤーカフ／オーリオの光 |
| 🟣 **パープルハット** | 紫 `#7B5EA7` | **Pup** | **コートの裏地**／左耳のイヤーカフ／ステルスの舌 |

## 2. イヤーカフ — 唯一の共通アイテム

小さく、スタイリッシュ。**機能はない。名乗りの記号**。付け方で個性を出す。

| 誰 | 付け方 |
|---|---|
| **ピコ** | 左耳。ライム。**小さなチャームがぶら下がっている**ので、動くたび **チャリ** と鳴る（＝うるさい主人公を、音で表す） |
| **シロ** | 右耳。白〜ティール。**普段はキャップに隠れて見えない**（第1話ラストで、初めて読者に見える） |
| **Pup** | 左耳に**2つ**。**紫**と、**黒**。黒は Wolves 時代のもので、**まだ外していない** |
| **ハウル** | 耳ではなく、**喉のチョーカー**。四牙は喉に着ける（＝格のちがい／声のモチーフ／飼われている暗示） |
| **クロ** | なし。**名乗る必要がない** |

> **Pup の2つが、そのまま 物語になっている。**
> 第10話で**黒を置いてくる**＝もう黒として通れない＝**群れに戻れない**。
> 帽子を落とすより、耳から片方 外して置いていくほうが、はるかに絵になる。

## 3. シルエット・テスト（親指サイズで見分けられるか）

**毎回やること**: 主要6人を**黒いシルエットだけ**にして並べる。それで見分けられなければ、
形が足りない。色やトーンで解決しようとしない。

| 誰 | 親指サイズでの見え方 |
|---|---|
| **ピコ** | 小さい。**髪がくしゃっと大きく外へはねている**。そして**常にノートPCを抱えている**（これが最大の識別記号） |
| **シロ** | 小さい。**つばの短いキャップの輪郭**。手足が体の内側にある（静） |
| **Pup** | 縦に長い。**肩から広がるコート**（袖を通していない）。前髪で片目が隠れる。**女の子** |
| **ステルス** | **細長い線が1本**。Pup の首か袖から伸びている |
| **オーリオ** | **まんまるの点**。ピコの肩の高さ |
| **プロック** | **もこもこの雲**。地面すれすれ |
| **ハウル** | いちばん縦に長い。**襟が高い**。手足が異様に長い |
| **Wolves 雑魚** | フードに**三角の耳／ネズミ耳／羽**。**群れなので、必ず複数で描く** |

**旧記述の訂正**: 「シロと Wolves がどちらもフードなので混同する」と書いていたが、
**シロはフードではなくキャップ**なので、この危険は最初から無かった（→ §0.5）。
Wolves のフードに動物の耳を立てる規約自体は、雑魚どうしの描き分けとして維持する。

## 4. Pup — リバーシブルのコート

**表 ＝ 黒（Wolves）／ 裏 ＝ 紫。**
「**両方 知ってる色**」が、服そのものになっている。潜入時は黒面、戻ると翻して紫面。

- 袖は通さず、**肩に掛けるだけ**（＝いつでも裏返せる／シルエットが広くなる）
- 第4話の正体開示は「フードをはたき落とされて帽子が転がる」ではなく、
  **「掴みかかられて、コートが翻り、裏地の紫が ばさりと 見える」**
- 中は、どこの国のものかわからない私服。**特定の国籍を感じさせない**こと
- 髪は黒に近いアッシュ。**前髪が長く、片目を隠している**（正体不明感）。目は淡い紫寄り
- **女の子**（オーナー判断 2026-08-03）。ただし可愛さで押さず、**かっこよさ**で押す——
  コートを肩掛けにするシルエットと、前髪で片目を隠す不透明さがそのまま効く。
  ステルスからの呼称は「**アネキ**」

---

## 5. フードを着るのは Wolves の雑魚だけ

主要キャラが誰も帽子をかぶらないぶん、**Wolves の動物モチーフのフードが際立つ**。
組織の制服＝**没個性であることが正しい**ので、ここは統一してよい。

- **ラット**（第1話）: ネズミ耳のフード。丸い前歯
- **モグラ**（第2・7話）: 土まみれ。ゴーグル。手が大きい
- **フライ**（第3・5話）: 背中に薄い羽。細い

**ハウル（四牙）はフードを着ない。** 雑魚と同じ制服を着ないことが、格の表現になる。

## 6. 声の吹き出し ― この作品でいちばん重要な仕様

**声を盗む敵がいる漫画なので、「誰の声か」が 吹き出しの形で わからないと 11〜14話が読めない。**

| 話者 | 吹き出し |
|---|---|
| **ピコ** | 丸みがあって、少しギザついた楕円。線が太い |
| **シロ** | 細い線・小さめの楕円。**ときどき枠が途切れる**（声が小さい） |
| **オーリオ** | 角の立った、几帳面な角丸長方形 |
| **プロック** | もこもこした雲形 |
| **ステルス** | 細長く、うねった吹き出し |
| **Pup** | 直線的な四角。角が鋭い |
| **ハウルが盗んだ声** | **元の持ち主の吹き出しの形を、そのまま使う。ただし、しっぽ（尻尾）だけが ハウルを 指している** |
| **ハウルの本当の声**（第14話） | **枠線がかすれて、途切れ途切れ**。他のどれとも似ていない |
| **クロ** | **枠が無い**。地の文のように、コマの中に文字だけが浮く |

> **この1行が、11〜14話を成立させる。**
> 読者は「八百屋の吹き出しなのに、**しっぽが ハウルを 向いている**」で、
> 説明ゼロで「声を盗まれた」を理解する。
> 第14話 P.3-4 の見開き（街じゅうの声が降ってくる）は、**全部の吹き出しのしっぽが
> 山頂のハウルを 向いている**ことで成立する。

## 7. 頭身

アニメ版の「日常チビ／バトル5-6頭身」の**2モードは採らない**。
週刊のページ数で変身バンクを毎回やる余裕がなく、シリアス回（8・9・12話）で
チビ絵に落ちると感情が死ぬため。**常時5〜6頭身、ギャグの瞬間だけ SD**（少年漫画の標準）。

| 誰 | 頭身 |
|---|---|
| ピコ | 5（子どもなので頭が大きめ） |
| シロ | 5（小柄。ピコより気持ち高い程度） |
| Pup | 6（中学生。手足が伸び始めている） |
| ハウル | 7（大人・細身・手足が長い＝**異物感**） |
| クロ | 不定（シルエットのみ。輪郭がにじむ） |

## 8. エージェントのサイズ規約

**手のひら〜抱き枕サイズに固定する。** 大きくすると主人公が霞む。

| 誰 | サイズ |
|---|---|
| **オーリオ** | ピコの肩に乗る。両手で抱えられる |
| **プロック** | 抱き枕サイズ。**ピコが抱きつける**（これがギャグの基本装置） |
| **ステルス** | Pup の首に巻ける太さ。伸ばして 1.5m 程度 |

戦闘時も**大きくしない**。技の派手さは、**光の量と スピード線**で出す。

## 9. モノクロ処理

本編は白黒。**意味を持つのは「形」と「トーン」だけ。**

- **シロ**: 白ヌキ（トーンをほとんど乗せない）。**画面でいちばん明るい存在**
- **ピコ**: パーカーに明るめのトーン（10%前後）。**はね毛は線だけ**
- **Pup**: コート表はベタに近い濃さ、**裏地の紫は 斜線のクロスハッチ**（＝翻った瞬間、質感が変わる）
- **Wolves**: **ベタ（真っ黒）**。群れで描くと画面が重くなるので、**背景は白く抜く**
- **ハウル**: コートはベタだが、**襟と喉のチョーカーだけ 白ヌキ**（＝喉に目が行く）
- **クロ**: ベタの中に**白い粒子ノイズ**。輪郭線を引かない

## 10. NG

- 主人公側に不良記号（タバコ・武器・ピアス多数）を持たせない。**イヤーカフは片耳1〜2個まで**
- 流血・欠損・腐敗を描かない（**倒す＝起こす**）
- デーモンに角・尻尾・三叉槍を描かない（**角なしの歯車ロボ**）
- ゴーストに白布・骸骨を描かない
- Wolves を**獣化させない**。あくまでフードとマーク（三本の爪あと）で表す
- 特定の国・宗教を想起させる記号を、キャラにも背景にも置かない
- ハウルを**同情的な美形にしすぎない**。目の下の隈と、笑いすぎる口元で、**気味悪さ**を残す
