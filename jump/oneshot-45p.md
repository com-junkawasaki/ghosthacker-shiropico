## 改訂（2026-08-03・第2版）— タダの原体験はアナログ、罪の拡大はデジタル

### 何を変えたか
第1版はパン屋、第1.5版は違法サイト。**第3版は両方使う。順番が要点。**
（オーナー判断 2026-08-03: 店は**パン屋のまま**。v6 の完成原稿がそのまま生きる）

| | 何が起きるか |
|---|---|
| **原体験（アナログ）** | **たけうちベーカリーの竹内さん**が、いつもタダでパンをくれる。無口だが、優しいから。
ピコはそれを**当たり前**だと思っている。ここに悪意はひとつも無い |
| **転移（デジタル）** | 同じ感覚のまま、**ネットでもタダで観る・遊ぶ**。
「もらっていい」と「取っていい」の区別がついていない |
| **拡大（決定的）** | **それを、みんなに広げてしまう。**
「みんなも タダで 観られるようにしたのだ！」——善意で、拡散する |
| **発覚** | それを**シロに見つかって、怒られる** |

**罪は「観たこと」ではなく「広げたこと」。** ここが第1版・第1.5版になかった段。
ピコは最後まで悪意を持たない。**優しさの延長で、いちばん大きな穴をあける。**

### 竹内さんは被害者にしない — **対比**にする

第1版はパン屋の店主を被害者にした（1年前のいたずらで店が傾く）。
**第3版では、竹内さんは最後まで無事で、最後まで優しいまま**。
彼は罪の原因でも被害者でもなく、**ピコの誤解の源**であり、同時に**答え**でもある。

刃はここ（終盤・P.40台）:

```
ピコ  「たけうちの おじさん。オレ、いつも タダで もらってたのだ」
竹内  「……そうか」
ピコ  「……あれ、なんで タダなのだ」
竹内  「……**あんたが、毎朝 来るからだ**」
```

**「タダ」ではなかった。** 竹内さんは「ピコが毎朝来ること」を受け取っていた。
無口な男が一言だけ言う——**この構図だから、説明にならずに済む**。
ピコが気づいていなかっただけで、**あれは交換だった**。

そしてネットで、**ピコは何も返していなかった**。観て、遊んで、広げただけ。
——ここで初めて、自分がやったことの形が分かる。

**シロの条件（掃除と料理）と、竹内さんの答えは同じことを言っている。**
シロは説教をせず、**交換を要求することで教えた**。二人が別々の場所で同じことを言うので、
ピコは逃げ場がない。

### シロが惜しむ
シロは怒ったあと、こう思う——**「センスはいいのにね」。**
ピコの腕は本物で、だからこそ**もったいない**。この一言が、
罰でも説教でもない「引き取る」動機になる。

### そしてペアが結成される
- ピコは**シロの技術を素直に「かっこいい」と思い**、「**師匠**」と呼ぶ
- シロは条件を出す——**「私の部屋を掃除して、ごはんを作ること」**
- シロは**掃除も料理もできない**。人にやってもらうと機嫌がいい
- **本当の理由は言わない**。毎日 目の届く所に置いて、
  ピコが無邪気に悪い方へ行かないようにするため。口では「部屋、汚いから」としか言わない
- ピコの作ったものを食べているシロ——**技術ではシロが上、台所ではピコが上**。
  この反転があるからバディになる（弟子ではなく）

### ペア結成は P.30台（オーナー判断: A）。**それでラストが変わる**

ペアが P.28-33 で結成されるので、**旧ラストの「シロが誘う → ピコが断る」は成立しない**
（もう一緒にいる）。組み直した結果、読切としてむしろ強くなった。

### 新しいラスト（P.45）

朝の給水塔。ピコが、よれよれのノートに鉛筆で大きく「**1**」と書く。
左耳のライムが朝日に光る。眼下の街に、ちいさな光がぽつ、ぽつと灯っている。

そして立ち上がり、**買い物袋を提げて、シロの部屋のほうへ歩き出す**。

```
M（ピコ）「ぜんぶには、とどかない。」
M（ピコ）「——でも、一個ずつなら。」
```

**「一個ずつ」が二重にかかる。** あけた穴を一個ずつふさぐことと、
毎日一食ずつ作りに行くこと。**同じ言葉が、責任と日常の両方を指す。**

## 読切と連載版の違い（ここを混ぜると読切が死ぬ）

**読切は「45ページで完結して、読者になにも借りを残さない」こと**が最大の条件。
連載第1話（`name-01.md`、48P）は逆に「借りを作って次を読ませる」ための設計なので、
**削って45Pにするのではなく、構造から組み直した**。

| | 連載第1話（`name-01.md`） | **本読切（`oneshot-45p.md`）** |
|---|---|---|
| 目的 | **借りを作る**（次号を読ませる） | **借りを残さない**（45Pで完結） |
| 出るキャラ | ピコ／シロ／オーリオ／プロック／ラット／**Pup／ステルス／クロ／デーモン／Wolves** | **ピコ／シロ／オーリオ／プロック／ラット／パン屋の竹内さん のみ** |
| 敵 | Wolves の末端（組織の氷山の一角） | **ただのコソ泥**。組織も黒幕もいない |
| 帽子／階級 | 4色の掟を説明する | **一切 出さない**（設定説明に1Pも使えない） |
| ラスト | 空港。世界地図。To be continued | **街に残る。ノートに「1」と書く。完** |
| ピコの到達点 | 「あけたら、ふさぐ」と言えるようになる | **自分があけた穴を、数えはじめる**（＝責任を引き受ける） |

### 読切にするための、いちばん大きな決断

**連載版の第1話（出会い）と第8話（忘れていた被害者）を、1本に畳んだ。**

連載版はピコの罪悪感を8話まで温存できるが、読切にその余裕はない。
**「ピコが毎朝ただでパンをもらっている店」が、1年前のピコのいたずらで傾いていた**
——この1点を物語の中心に据えることで、45Pでも読者の胸に穴があく。

そして**ラストで旅に出さない**。連載版は旅立ちで終わる（＝始まり）が、読切は
**「まず、自分があけた穴を数える」**で終わる（＝終わり）。同じキャラで、ベクトルが逆。
これで「続きが読みたい」ではなく「いい話を読んだ」で本を閉じられる。
