# 『GHOST HACKER ― シロとピコ』 第3話ネーム

## 「たすけて、って言われたのだ」

**19P／週刊連載 第3話**
Arc 1 構成は `jump/arc-01.md` ／ 企画書は `jump/SERIES-PROPOSAL.md`

### ネーム記法
- ページ見出しの `右` / `左` は右綴じでの位置。**`左` ページの最終コマが「めくり」＝ヒキ**
- `◀ めくり`＝引きのコマ、`◆ 見開き`＝2ページぶち抜き
- 数字はコマ番号、`【 】` は構図、`>` はセリフ、`SE:` は効果音、`M:` はモノローグ

### 第3話の設計
| 項目 | 内容 |
|---|---|
| イキり | 「オレ、もう ふさぐの じょうずなのだ」 |
| **やらかし** | **人を信じすぎる**。「困ってる、カギを貸して」と言われて、素直に渡す |
| 悪化 | 渡したカギで、**街じゅうの扉が いっせいに 開く**。ピコの善意が、そのまま被害になる |
| シロの問い | 「**やさしいのは、いいこと。……でも、確かめた?**」 |
| ピコの答え | 「**しんじるのは、やめないのだ。たしかめてから、しんじるのだ**」 |
| 敵 | **フライ**（ハエ）。**声真似が得意** ← **Arc 1 最大の伏線** |
| 獲得 | **《伝書（メッセンジャー）》** — 本人のところへ飛んで、直接 聞いてくる |
| 縦軸 | フライの口が滑る「**ハウルの兄貴**が——」／夜、遠くで**遠吠え** |

> **この回のいちばん大事な一線**
> **ピコに「人を信じるな」を学ばせない。** それをやると、この作品の主人公の芯（純粋さ）を
> 折ることになる。学ばせるのは「**信じる前に、本人に 聞け**」という**手順**だけ。
> 性格は矯正しない ——「ピコは最後までやんちゃ」は Arc 1 の不変条件。
>
> **フライの声真似は、ここで"種"として1回だけ使う。** 大々的に見せない。
> 読者が「あ、声を真似したんだ」と後から気づく程度に留め、**5話で恐怖として、
> 11〜14話で 脅威として** 育てる。
