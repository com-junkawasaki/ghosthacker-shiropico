# 『GHOST HACKER ― シロとピコ』 第10話ネーム

## 「もどる むらさき」

**19P／週刊連載 第10話 — Pup 主役回（ピコは、待つ側）**
Arc 1 構成は `jump/arc-01.md` ／ 企画書は `jump/SERIES-PROPOSAL.md`

### ネーム記法
- ページ見出しの `右` / `左` は右綴じでの位置。**`左` ページの最終コマが「めくり」＝ヒキ**
- `◀ めくり`＝引きのコマ、`◆ 見開き`＝2ページぶち抜き
- 数字はコマ番号、`【 】` は構図、`>` はセリフ、`SE:` は効果音、`M:` はモノローグ

### 第10話の設計
| 項目 | 内容 |
|---|---|
| イキり | **なし**（緊張から始める） |
| **やらかし** | **待てない**。「助けに行くのだ！」と飛び出しかける |
| 悪化 | 動けば Pup が終わる。**何もしないことが、いちばん難しい** |
| シロの問い | 「**信じるって、なにもしないこと**」 |
| ピコの答え | 待つ。**行く前に《置き羽》を渡してある**。それが全部 |
| 見せ場 | ステルス《脱皮（シェッド）》《ヒートサーチ》。**潜入中に喋りすぎる** |
| 縦軸 | **ハウル初登場**（声と背中だけ／顔は出さない） |
| 引き | Pup は帰ってくる。ただし**黒いイヤーカフを、置いてきた**（＝Wolves 時代の身分証） |

> **この回の構造**
> ピコの唯一の貢献は、**話が始まる前に**終わっている（P.3-4 で《置き羽》を押しつける）。
> 本編19ページのあいだ、ピコは**なにもしない**。それでも最後に Pup を救うのは、その羽。
> **「信じる」を、能動的な行為でなく、事前準備＋不作為として描く**のがこの回の芯。
>
> **視点は二重**。外のピコ（なにも見えない）と、中の Pup（読者には見える）を交互に出す。
> 読者だけが両方を知っているので、ピコの焦りが「わかるけど、やめてくれ」になる。
